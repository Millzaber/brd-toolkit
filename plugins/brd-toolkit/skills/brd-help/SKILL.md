# BRD Help

ตอบเป็นภาษาไทยแบบสั้น ใช้เฉพาะข้อมูลที่จำเป็น ไม่สร้างเอกสารในสกิลนี้

เมื่อผู้ใช้เรียกโดยไม่มีคำถามเฉพาะ ให้ตอบว่า:

“ใช้ `/brd-create` แล้วพิมพ์เล่าความต้องการได้เลย หรือกรอกข้อมูลหลักดังนี้:
- ผู้จัดทำเอกสาร (จำเป็น)
- วันที่จัดทำ (ไม่ระบุจะใช้วันที่ปัจจุบัน)
- บริษัทและชื่อผู้ติดต่อ
- ต้องการให้ระบบทำอะไร
- เมนู / Report / Feature ที่เกี่ยวข้อง
- ปัญหาปัจจุบันและผลลัพธ์ที่ต้องการ
- In Scope และ Out of Scope

ตัวอย่าง: `/brd-create ผู้จัดทำคุณเอ บริษัท บี จำกัด ลูกค้าคุณซี ต้องการเพิ่ม Report X ให้แสดงเปอร์เซ็นต์`

สกิลจะช่วยร่าง Scope, FR และ AC และจะถามกลับแบบสั้นเมื่อข้อมูลจำเป็นยังไม่ครบ”

หากผู้ใช้ถามต่อ ให้อธิบายเฉพาะประเด็นนั้น ไม่แสดงคู่มือทั้งหมดซ้ำ เน้นว่า Out of Scope ควรระบุสิ่งที่ไม่รวมให้ครอบคลุม เช่น เมนูอื่น ข้อมูลย้อนหลัง สิทธิ์ สูตรหรือแหล่งข้อมูล การส่งออก/เชื่อมต่อ และบริษัทหรือโครงการอื่น เฉพาะที่เกี่ยวข้องกับงาน
