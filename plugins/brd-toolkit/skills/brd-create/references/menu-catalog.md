# รายการเมนูที่เกี่ยวข้อง

สถานะ: รอผู้ใช้ส่งรายการทางการ ยังไม่มีรายการที่ยืนยัน

| ชื่อทางการ | ชื่อเรียกอื่น (Alias) | ประเภท Menu/Feature/API/Form/Report | Module หรือ Path | คำอธิบาย/ข้อจำกัด |
|---|---|---|---|---|

Materials ในเอกสารต้นฉบับเป็นข้อมูลตัวอย่างของงานหนึ่ง ไม่ใช่ catalog ทางการ
ระหว่างรอรายการ ใช้ชื่อจากผู้ใช้ตามที่ระบุ อย่าเดาหมายเลขเมนูหรือ path
เมื่อรับรายการใหม่ให้เก็บชื่อทางการตามต้นทาง ใช้ alias เพื่อช่วยจับคู่เท่านั้น และถามเมื่อจับคู่ได้หลายรายการ
